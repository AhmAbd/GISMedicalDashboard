# GIS Medical Dashboard

تطبيق ويب لمتابعة المنشآت الطبية وسيارات الاسعاف وحالات الطوارئ في سوريا من خلال خريطة تفاعلية.

تعرض اللوحة حالة المنشآت ونسبة الاشغال، وتتيح متابعة سيارات الاسعاف والتنبيهات والرجوع الى حالة البيانات في وقت سابق.

[عرض المشروع](https://gismedicaldashboard-psi.vercel.app)

## تشغيل المشروع محليا

لتشغيل المشروع تحتاج الى `Node.js 24` أو احدث، بالاضافة الى `Docker Desktop`.

انشئ ملفا باسم `.env` في مجلد المشروع، ثم اضف اليه القيم التالية:

```env
DATABASE_URL=postgresql://medical:medical@localhost:5432/medical_tracker
PORT=4000
```

ثبت الحزم وشغل قاعدة البيانات:

```powershell
npm ci
docker compose up -d
npm run db:seed
```

بعد ذلك شغل الخادم والواجهة في نافذتين منفصلتين:

```powershell
npm run dev -w backend
npm run dev -w frontend
```

افتح `http://localhost:3000` في المتصفح.

يمكنك التأكد من أن المشروع يبنى بشكل صحيح باستخدام:

```powershell
npm run build
```

## ماذا يفعل المشروع؟

- يعرض المنشآت الطبية وحالتها على الخريطة.
- يعرض نسبة الاشغال وعدد الاسرة المتاحة في كل منشأة.
- يتيح تصفية البيانات حسب المحافظة ونوع المنشأة.
- يعرض سيارات الاسعاف وحالات الطوارئ والتنبيهات.
- يتيح الرجوع الى آخر حالة مسجلة عند اختيار وقت سابق.
- يحاكي تغير الاشغال وحركة سيارات الاسعاف وظهور حالات طوارئ جديدة.
- يختار اقرب سيارة اسعاف متاحة وينشئ مسار التوجيه الخاص بها.

## القرارات المعمارية

- انشأت نسخة محلية تجريبية `mock` من مكتبة `react-med-geo-streamer@2.1.0` لتحاكي طريقة عمل المكتبة المطلوبة في المشروع. تحتفظ المكتبة بحالة لوحة المراقبة خارج مكونات `React` باستخدام `useSyncExternalStore`، وتجلب البيانات من `/api/state`. عند وصول تحديث من `WebSocket` برسالة `medical:update` تعيد تحميل البيانات حسب الفلاتر المختارة.
- اعتمدت على `PostgreSQL` و`PostGIS` لحفظ البيانات وتنفيذ الحسابات، مثل عدد الاسرة المتاحة والمسافات والتجمعات ومسارات سيارات الاسعاف.
- استخدمت `Express` و`Socket.IO` في الخادم للتعامل مع البيانات والتحديثات المباشرة. واستخدمت `Next.js` و`React` لبناء الواجهة.
